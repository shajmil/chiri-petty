# Public reference research

Inspected 2026-10-23. Sources: https://mimicparty.net/, https://mimicparty.net/how-to-play/, https://mimicparty.net/faq/.

The current public browser edition describes a solo voice imitation game, separate from the Steam product. Verified from the public page: one reference listen, one recording, replay before score, local sound-shape scoring, packs, four-round quick play, survival mode, settings, bonus wheel, and local voice processing. This is public page/documentation evidence, not an executed reference match.

Private multiplayer rooms, 2–8-player limits, simultaneous cross-device recording, voice chat, targeted opponent sabotage, host recovery and shared storage could not be verified at this URL. These are Chiri Party requirements, not claimed reference parity.

Independent implementation: original Malayalam text, procedural 3D artwork and locally synthesized reference WAVs. Synthesized animal and human sounds are stylized imitable cues, not recordings of animals or actors. Dialogue references represent delivery rhythm; no speech-recognition accuracy is claimed.
